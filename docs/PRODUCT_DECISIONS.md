# Locked Awaazify V1 decisions (2026-10-19)
- YouTube URL and audio upload are both required V1 input paths. Download/processing only for authorized material; metadata fallback and upload alternative for unavailable sources.
- First complete cover free, limited to 6 minutes, atomically once per account; abuse mitigation required beyond single-account enforcement.
- Custom RVC voice training: manual Google Colab workflow, trusted model validation and owner-private publication.
- Song retention: permanent by default (no automatic time-based deletion). Storage plans, budgets, service continuity, legal takedowns and user deletion requests remain necessary; do not claim unlimited free storage.
- Visual design: minimal light theme.
- Payment: manual verified EasyPaisa/JazzCash top-ups; no fake card UI. International payments need a verified method before global checkout launch.
- Public voices: originals or permissioned/contracted voices; no unlicensed celebrity/public-figure commercial catalog.
- Phase 1 is foundation only, not a finished product.
